# Pony Cards 2.51 — moving columns, random boss attacks and coin rewards

- Level 3: every sixth column now moves gently up and down, with its gap moving as one obstacle.
- Boss attacks now select patterns randomly without repeating the same pattern twice in a row. Projectile volleys vary in size; lasers can target one lane or three, and black holes can appear early.
- Boss damage counter is now exclusive to the infinite boss-training mode.
- Boss training now spawns collectible coins, pays out collected coins when the run ends, and saves a persistent best-damage record.
- Added the best boss-damage record to the home screen beside the collection and column records.
- Added the 300×300 transparent golden coin artwork used by the wallet, shop prices, and in-flight pickups. Coins spin, glow, and animate away when collected.
- Pack-opening modal close button is fixed to the top-right; the two-line heading is centered independently.
- Added a safe database migration for the new best boss-damage field.
