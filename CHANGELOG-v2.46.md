# Pony Cards 2.46 — исправление открытия набора

- Рубашка набора отображается целиком одним изображением 2:3 без отдельной рамки и пустой подложки.
- Переворот выполняется между двумя полными изображениями карты.
- После переворота показывается только лицевая сторона карточки; название, редкость, описание способности и отметка «ДУБЛИКАТ» размещаются отдельно под изображением.
- Устранено наложение старой карточной рамки/контейнера на изображения.
- Обновлены версии CSS и JavaScript в ссылках, чтобы браузер загрузил новые файлы.

Примечание: `card-back.png` остаётся пользовательским файлом и должен находиться в `src/main/resources/static/assets/ui/card-back.png`.
