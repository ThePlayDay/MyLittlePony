## Изображения карточек

- Папка: `src/main/resources/static/assets/user-content/cards/`
- Манифест: `src/main/resources/static/assets/user-content/asset-manifest.json`
- Имена файлов: `<ID>.png`, полный список в `cards/README.txt`.
- Первые три изображения уже положены в папку: `starlight.png`, `berry.png`, `cloudy.png`.
- Для остальных 11 достаточно добавить PNG с точным именем; JS и Java менять не нужно.
- Формат рекомендуется PNG, портрет 3:4, например 768×1024.

## Технические изменения

Используются только уже реализованные движком типы эффектов:
`SHIELD`, `SLOW_WORLD`, `JUMP_POWER`, `MAGNET`, `EXTRA_COIN`, `COIN_BONUS`.
Поэтому способности действительно работают в полёте; новые неисполняемые эффекты не добавлены.
Отсутствующее изображение заменяется заглушкой, не ломая каталог и магазин.
